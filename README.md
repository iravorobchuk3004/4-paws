# 🐾 4 Paws

Мобільний застосунок для адопції тварин із притулків. У ньому можна знайти собі улюбленця за способом життя, допомогти тварині донатом, якщо ви поки не готові забрати її додому, або швидко повідомити про знайдену тварину.

Зроблено на **Expo (React Native)**, працює на iOS та Android.

## Як запустити

Потрібні [Node.js](https://nodejs.org) 20+ і застосунок **Expo Go** на телефоні ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)).

```bash
git clone https://github.com/iravorobchuk3004/4-paws.git
cd 4-paws
npm install --legacy-peer-deps
npx expo start
```

Відскануйте QR-код із терміналу: на iPhone камерою, на Android через Expo Go. Телефон і комп'ютер мають бути в одній Wi-Fi мережі.

> Усі дані зберігаються локально на пристрої, сервер не потрібен. Щоб повернутися до реєстрації, натисніть **Profile → Log out**. Інтро показується лише під час першого запуску; щоб побачити його знову, очистіть дані застосунку в Expo Go.

## Що вміє

**Старт і онбординг**
- Анімований сплеш: лого обертається, а назва складається з відбитків лап.
- Інтро з маскотами з Figma: хвостики виляють, лапки рухаються. Щоб почати, треба «дати лапу», тобто натиснути й утримати кнопку.
- Реєстрація, вхід і відновлення пароля.
- Вибір мети («хочу взяти тварину» або «хочу допомогти») та анкета «A little about you».

**Адопція**
- Головний екран із категоріями: цуценята, кошенята, кролики, птахи, спокійні сеньйори, активні собаки.
- Відсоток збігу з кожною твариною рахується з відповідей в анкеті (активність, житло, час, діти, інші тварини).
- Сторінка тварини: факти, здоров'я, характер, карта притулку з маршрутом.
- Заявка на адопцію з таймлайном статусу, зустріччю в притулку та контактами.

**Допомога**
- Донати на догляд за конкретною твариною з прогресом збору.
- **Treat Run**: міні-гра на весь екран з улюбленою твариною. Кожні 50 зібраних кісточок перетворюються на справжню порцію корму для тварини з притулку.

**Знайшла тварину**
- Три кроки: фото (можна замінити чи видалити), місце на живій карті з геолокацією, потрібна допомога.
- Сторінка звернення з оновленнями та закриттям кейсу.

**Спільнота**
- Happy tails: історії тварин, які знайшли дім. Можна додати свою історію й поділитися нею.
- Сповіщення, «Моя активність», профіль із фото.

## Стек

| | |
|---|---|
| Фреймворк | Expo SDK 58, React Native 0.88, React 19 |
| Навігація | Expo Router (файлова маршрутизація в `src/app`) |
| Стан | React Context + AsyncStorage |
| Карти й геолокація | react-native-maps, expo-location |
| Інше | expo-image, expo-image-picker, expo-haptics, Animated API |
| Мова | TypeScript |

## Структура

```
src/
  app/          екрани (кожен файл — окремий маршрут)
    (tabs)/     головні вкладки: Home, Matches, My pets, Support, Profile
    onboarding/ реєстрація та анкета
    found/      флоу «Знайшла тварину»
    play/       гра Treat Run
  components/   UI-компоненти (картки, мапа, маскоти, таймлайн…)
  data/         демо-дані тварин і притулків
  lib/          логіка: підбір за анкетою, геолокація, сповіщення
  store.tsx     стан застосунку зі збереженням на пристрої
  theme.ts      кольори й шрифти з дизайн-системи
assets/
  pets/         фото тварин (CC0 / public domain, джерела в CREDITS.json)
  mascots/      маскоти з Figma, розрізані на шари для анімації
```
